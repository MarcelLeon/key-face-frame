# 给 Mac 视频创作者的选帧小工具

做人物视频，找封面、找参考画面时，总要反复拖时间轴。

介绍一下自己的产品：盯亿帧 Key Face Frame。已经上架 Mac App Store，今天把独立官网也做好了。

它做的事很具体：
① 导入 Mac 上的本地视频
② 检测人物，按人物大小、置信度、居中等因素筛选候选帧
③ 自己复核，导出 PNG、时间标记 CSV 或 ComfyUI 离线素材包

视频在本机处理，不上传开发者服务器。也支持批量处理和本地历史。

先把边界讲清楚：它不识别人物身份，不自动剪辑或生成视频；光线、遮挡、运动会影响结果，分数不等于“最好看”。CSV 可能需要转换，ComfyUI 素材包也需要你自己的后续工作流。

适合用来整理人物镜头、挑封面候选、做剪辑前选材。

macOS 14+、Apple 芯片，可先免费体验 3 个单视频，再决定是否永久解锁。

官网：https://key-face-frame.pages.dev/
Mac App Store 搜索「盯亿帧」。
