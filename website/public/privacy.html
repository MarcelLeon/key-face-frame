App 的数据处理

盯亿帧 1.0 在 Mac 本机进行视频抽帧和人物分析，无需注册账号。原视频、抽样帧和关键帧不上传开发者服务器。App 不使用第三方广告、跨 App 追踪或自建行为分析 SDK。

本地历史保存于 Mac 的 Application Support 目录；导出内容保存在你选择的位置。主动导出的诊断包可能包含文件名称、参数和历史摘要，不包含原视频或关键帧，也不会自动上传。分享前请自行检查。

购买与主动反馈

永久解锁由 Apple StoreKit 处理，支付资料、退款与购买历史遵循 Apple 政策。通过邮件或 GitHub 主动反馈时，开发者只使用你提供的信息处理请求。GitHub Issue 为公开内容，请勿上传敏感素材。

这个宣传网站

网站只展示产品信息，不提供视频上传或处理功能，不使用 Cookie 追踪、广告或第三方行为分析脚本。字体、图片和脚本由本站提供。

网站托管在 Cloudflare。浏览页面时，IP 地址、请求信息等网络数据会经过托管服务，用于内容传输、安全和基础运行；这不等于 App 上传了你的视频。外部 App Store 与 GitHub 链接适用各自的隐私政策。
